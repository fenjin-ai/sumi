Sumi uses the following bundled components:

Tinymist v0.15.8 (MIT)
https://github.com/Myriad-Dreamin/tinymist/tree/v0.15.8
Binary contains Typst 0.15.1 (Apache-2.0), from Tinymist's pinned upstream fork.
https://github.com/Myriad-Dreamin/typst/tree/tinymist/v0.15.1
See Tinymist-LICENSE and Typst-LICENSE.

Phosphor Icons Regular (MIT)
https://github.com/phosphor-icons/core/tree/2b75f3ad12b420c9504ef05df8d2564a28f8500e
SVG source icons converted to vector PDF using librsvg for AppKit.
See Phosphor-LICENSE.

App icon is an original Sumi vector mark (AppIcon.svg): a continuous ivory capital Sigma on charcoal, generated by design/sigma/generate.py using golden-ratio geometry and a sine pressure envelope. No third-party logo artwork or font outlines are used in the mark.
Nano Emacs and Spacemacs inspired the visual and command-discovery design;
no source code from either project is bundled.

The bundled SumiMCP helper uses the official MCP Swift SDK 0.12.1
https://github.com/modelcontextprotocol/swift-sdk/tree/0.12.1
MCP SDK (Apache-2.0 and MIT), Swift System / Swift Log (Apache-2.0 with Swift exception), and EventSource (MIT).
Full dependency license texts are in Licenses/. Resolved versions are recorded in Package.resolved.

Code notes includes codly 1.3.0 and codly-languages 0.1.1 (MIT).
https://typst.app/universe/package/codly/
https://typst.app/universe/package/codly-languages/
Original license notices and package contents are in Packages/preview/.
Archive provenance and checksums are in Packages/README.md.

Highlight.js 11.11.1 common language bundle (BSD-3-Clause)
https://github.com/highlightjs/cdn-release/blob/11.11.1/build/highlight.min.js
