LeftBlank offline Universe catalog

Source: https://packages.typst.org/preview/index.json
Captured: 2026-10-01 (UTC)
Contents: 1,643 package metadata records, latest published version per package.

This is a discovery snapshot, not package code or a promise that a package is
already installed. Original names, descriptions, authors, package licenses,
categories, compiler requirements and template metadata are retained. Source
code and thumbnail images are requested separately only when needed.

Refresh from the repository root:
  source scripts/environment.sh
  python3 scripts/update-universe-snapshot.py

For a reproducible refresh from a previously downloaded official index:
  python3 scripts/update-universe-snapshot.py --index /absolute/ssd/path/index.json --date YYYY-MM-DD

Review the resulting metadata diff and update the capture date/count above.
The online catalog and its 24-hour disk cache take precedence over this snapshot.
The bundled snapshot is not written into the network cache, so it cannot delay
an online refresh.

Official repository: https://github.com/typst/packages
The repository infrastructure is Apache-2.0; individual package licenses are
recorded on each entry and remain visible in LeftBlank's detail pane.
