# War and Peace stress fixture

Leo Tolstoy, translated by Louise and Aylmer Maude. Downloaded from
[Project Gutenberg, ebook 2600](https://www.gutenberg.org/ebooks/2600).
The complete downloaded source and its Project Gutenberg license notice are
preserved in `war-and-peace.txt`. The work is public domain in the United States.

`war-and-peace-highlighted.typ` escapes Typst markup in the prose, promotes
chapter labels to headings, and adds 39 small, clearly marked benchmark blocks
with Python, mathematics, emphasis and mixed Unicode. It is a stress fixture,
not a new literary edition. `manifest.json` records the source and output hashes.

Regenerate using `scripts/prepare-large-document.py`. Added benchmark material
and the preparation script use Sumi's repository license; the included book
retains its own source notices.
